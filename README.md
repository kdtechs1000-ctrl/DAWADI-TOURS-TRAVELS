# DAWADI Tours & Travels 🏔️✈️

A modern, full-featured web application for **Dawadi Tours & Travels**, built with React, Vite, Tailwind CSS, and Supabase. Designed to provide seamless tour bookings, destination explorations, hotel listings, transportation services, and real-time user communications.

---

## 🌟 Key Features

* **Interactive Navigation Bar (`Navbar.jsx`)**: Responsive single-line layout with dynamic color accents for each active route, custom branding badges, and mobile sheet navigation.
* **Tours & Adventures Search**: Advanced filtering with 4-digit year validation on travel dates to prevent invalid entries.
* **Real-time Contact & Support System**: Direct messaging interface for guest and user inquiries powered by Supabase.
* **Secure User Bookings**: RLS (Row Level Security) protected booking system guaranteeing that users can only manage and delete their own reservations.
* **Admin Dashboard**: Real-time admin views for incoming messages and bookings featuring automatic conversion of database UTC timestamps to Nepal Standard Time (NPT, UTC+5:45).
* **Supabase Realtime Sync**: Instant data reflection across components without manual page refreshes.

---

## 🛠️ Tech Stack

* **Frontend:** React, React Router DOM, Vite, Tailwind CSS, Lucide Icons, Shadcn UI components.
* **Backend & Database:** Supabase (PostgreSQL, Row Level Security, Realtime Subscriptions).
* **Deployment/Version Control:** Git & GitHub
